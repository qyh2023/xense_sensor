# FSC-2A 单轴运动控制器上位机

这是一个面向 Windows 的轻量上位机，依据《FSC-2A 单轴运动控制器使用说明书》中的 Modbus RTU 协议实现。

功能：

- 连续读取当前位置：`0x004A`（高）+ `0x004B`（低）
- 连续读取当前速度：`0x004C`（高）+ `0x004D`（低）
- 连续读取并显示 32 位输入口原始状态：`0x004E`（高）+ `0x004F`（低）
- 输入状态发生变化时写入通信记录
- 读取和设置正转速度 `0x0005/0x0006`、反转速度 `0x0027/0x0028`
- 写线圈 `0x0004`，停止运动
- 标定原点：先将控制器当前位置清零，再以反转命令向上寻找正限位，停稳后以正转命令向下移动 50 mm，并再次将当前位置设为 0
- 标定成功后通过绝对运动返回已标定的 0 mm 原点
- 通过同一 RS485 总线向压力变送器寄存器 `0x005E` 写入 `0x0001`，执行测量前清零
- 自定义最大力，持续读取变送器毛重 `0x0050/0x0051`；正负力的绝对值超限时立即写 FUYU 停止线圈 `0x0004`
- CRC16、响应站号、功能码、长度和回显校验
- 后台通信，不阻塞界面；严格保证相邻 Modbus 请求至少间隔 20 ms

## 接线与通信参数

控制器使用 RS485，RJ45 的 4、5 号引线分别是 `485_A`、`485_B`。请通过 USB-RS485 转换器连接电脑。

默认参数：

- Modbus RTU
- 站号：1
- 波特率：115200 bps
- 数据格式：8N1（8 数据位、无校验、1 停止位）

如果无法通信，请先核对 A/B 是否接反，以及控制器 P09（站号）和 P13（485 波特率）。说明书给出的 P13 映射为：0=2400、1=4800、2=9600、3=19200、4=38400、5=57600、6=115200。

变送器与 FUYU 运动控制器共用同一 RS485 总线。变送器自动复用 FUYU 的串口和波特率，界面只需设置变送器站号，默认为 `2`。两台设备的 Modbus 站号必须不同。

> 说明书没有明确写出输入口状态 32 个位与 IN0/IN1/IN2 的对应关系，因此界面显示寄存器原始十六进制值，并在状态变化时把变化位写入通信记录。

## 运行

```powershell
python -m pip install -r requirements.txt
python app.py
```

本机已经安装依赖时，直接运行 `python app.py` 即可。

也可以双击 `启动上位机.bat`。

## 验证协议实现

```powershell
python -m unittest -v
```

测试覆盖说明书给出的 CRC 示例、32 位有符号/无符号数据合并、六寄存器监视读取和停止线圈写入。

## 使用顺序

1. 控制器断电时完成 RS485 接线，确认机构和限位安全后上电。
2. 运行上位机，选择 COM 口、波特率、站号和轮询间隔；“ISS35细分”填写驱动器调试软件中的每转脉冲数。本机根据 `50 mm` 指令对应 `100 mm` 实测行程反推默认值为 `2500 pulse/rev`。
3. 点击“连接”。上位机会把ISS35细分同步到FSC-2A的细分寄存器并回读校验，随后当前位置、速度和输入状态自动更新。
4. 点击“标定原点”：程序先通过线圈 `0x000D` 将当前位置清零；控制器随后以反转命令向上运动。控制器自身因物理正限位停止后，该点被标记为 `+50 mm`；程序以正转命令向下移动，并在逻辑位置到达 `0 mm` 时主动发送停止命令。停稳后再次把中心设为 `0 mm`。
5. 标定成功后“启动回零”按钮才会启用；点击后通过绝对运动返回 0 mm。
6. 测量前确认变送器处于稳定状态且力值在手动置零范围内，设置正确的变送器站号后点击“变送器清零”。
7. 输入最大允许力（单位与变送器面板显示单位相同），点击“应用并启用”。保护触发后会锁定标定和回零按钮，排除原因后需重新布防。

标定不依赖 `0x004E/0x004F` 的输入位映射，而以控制器已经开始运动、随后自行停止作为物理限位触发信号。断开或重新连接控制器后，需要重新标定才能启用“启动回零”。

控制器协议只支持通过线圈 `0x000D` 将当前位置设置为 0，不支持直接写成任意位置。因此正限位处的 `+50 mm` 使用上位机坐标偏移实现：控制器在正限位处内部清零，上位机显示时加 50 mm；返回中心后再次清零并撤销偏移。

向下回退时包含独立的软件停止保护：逻辑位置到达或小于 0 mm 后立即写停止线圈 `0x0004`，等待速度连续两次为 0 后才执行中心清零。如果速度在逻辑位置仍大于 0 mm 时提前归零，标定会失败。由于FSC反转现在对应机构向上，界面位置采用反号换算，确保向上为正、向下为负。

当前位置寄存器按控制器的导程和细分参数动态换算：`计数/mm = 细分 ÷ 导程`，`毫米 = 原始位置 ÷ (细分 ÷ 导程)`。当前配置为导程 `10 mm`、ISS35细分 `2500 pulse/rev` 时，共 `250 计数/mm`，即 `0.004 mm/计数`。此参数同时决定FSC-2A实际输出的脉冲数量，因此能够同时修正显示距离、物理距离和物理速度，不能只在界面上将位置乘以比例。当前速度按控制器报告的 mm/s 显示，输入状态按无符号 32 位显示。

“停止运动”是普通通信控制命令，不应替代符合设备安全要求的硬接线急停装置。

最大力保护也是基于 RS485 轮询和软件停止命令的辅助保护，不是安全等级的硬件急停。力值连续 3 次读取失败且机构正在标定或回零时，程序会按故障安全方式发送停止命令并锁定保护。

手动急停、力值越限以及软件检测到的运动边界停止共用同一套停止发送逻辑：先终止当前标定/回零状态，再高优先级写停止线圈 `0x0004`；应答超时时最多重试 3 次。共享 RS485 总线的请求间隔从上一笔事务响应结束后开始计算，避免在变送器与 FUYU 之间切换时连续发帧。
